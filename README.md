# Personal Landing Page

An earlier personal portfolio/CV site — React + TypeScript + Vite, with bilingual support (English/Spanish via i18next) and a few custom interactive touches (magnetic buttons, custom cursor, glow cards).

## Sections

Hero, About, Skills, Experience, Education, Contact, with a shared Navbar/Footer.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS
- Framer Motion (page/section animations)
- i18next + react-i18next (EN/ES)
- react-router-dom

## Running it

```bash
npm install
npm run dev
```
